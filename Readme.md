Credits to Sir [Krish Naik](https://youtu.be/o126p1QN_RI)

## How to run?

- `uv venv`
- `.venv\Scripts\activate`
- `uv add -r requirements.txt`
- add [data](data) - pdfs
- Create .env with Groq Api Key ([example](.env.example))
- `python app.py`
